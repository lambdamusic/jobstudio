*How this list works.* Tasks are grouped by theme. To mark a task for an interview
round, end its description with that round's tag: `@hr-screen`, `@hiring-manager`,
`@technical`, `@panel`, `@final` or `@informal`. The round's page then gathers its
tagged tasks without copying them, so a tick on either page is the same tick. A task
with no tag is general prep. Add tasks by writing them straight into this file under
the right theme, as `- [ ] **Short title.** Longer description. @tag`; a note on how
it went can follow as an indented sub-bullet.
