{# ----------------------------------------------------------------- §4 stock #}

Status over time

What shape is the pipeline, and what moved each week?

{% if stock.ready %}
{% include "tracker/_chart.html" with key="stock" height=300 label="Step chart, two views: how many applications sat in each status week by week, and how many arrived in each status each week" %}

Stacked. Stock, not events — the dashboard's Activity chart counts what happened each week; this counts where everything was, so the top of the pile is the size of the tracker. Steps rather than a curve: a status changes on a day, and a smooth line between two weeks would invent the days in between. {% if stock.reconstructed %}{{ stock.reconstructed }} of {{ stock.weeks|length }} week{{ stock.weeks|length|pluralize }} {{ stock.reconstructed|pluralize:"is,are" }} shaded: their history was reconstructed by the 2026-09-08 backfill, which dated rows from the day an application was logged, or arrived in one bulk logging session. The shape there is when things were recorded, not when they happened.{% endif %}

What moved each week. Not the same numbers drawn differently — this counts applications that arrived in a status during that week, so it falls back to zero in a quiet week where the other view would hold a flat line. It is the reading that can be followed one status at a time: in a stack a band's thickness is its own value but its height is everyone else's, so a status that never moved still appears to. {% if stock.reconstructed %}The shaded weeks matter more here than anywhere: a bulk logging session is a spike in this chart that never happened on that scale.{% endif %}
