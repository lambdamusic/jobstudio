Built for interview rounds (`#66`) and reused unchanged by My notes and Other files (`#72`) — the only interview-shaped things in it were the two arguments below. `

It collapses with no JavaScript, it is keyboard-operable and screen-reader-announced for free, and the browser's own find-in-page can open it — none of which a hand-rolled toggle gets without work. `section-nav.js` adds two things on top: opening the right block when a pill or an inbound `#...` link targets something inside it, and highlighting the pill you are reading. Arguments: doc `parsers.sectioned()` output — preamble_md, blocks, body_md. qa true for an interview round. Questions are marked, numbered and folded in every document (`**Q:**` lines, `qa_items`); this only makes the heading rule loose, since a round's headings are mostly questions and a note's are topics (`mark_qa`). open render the sections expanded. A judgement per tab, not a global default — see the note where each include passes it. {% endcomment %} {% comment %} `data-hl-source` is what highlight.js keys on: a document it can write a highlight back to.
