{% comment %} One tab per group, each an index of its notes (2026-10-08). It was one tab per note (`#73`) until study material carried over from applications took it past a dozen tabs. A group is a subfolder of jobs/notes/ (`views.NOTE_GROUPS` gives the known ones their names and order). Each line links the note's own page, which has its Contents list. "Used in" lists the applications whose folders link to the note, worked out from the links themselves (`_note_backlinks`). It is what says which conversation a note served, without anyone keeping that up by hand. Without JavaScript every panel renders, so this is one long page rather than a broken one — the same bargain `tabs.js` makes everywhere. {% endcomment %} {% if groups or coach %}
