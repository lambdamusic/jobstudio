{% comment %} One tab per note, with the same jump index the Interviews tab and My notes use (`#73`). **The per-note pages at `/notes//` are kept, not replaced.** They are what `build_static` publishes, and the honest target for a link from outside the app. This page is for moving between notes without a trip through a list and a back button; each panel links its own page for reading one on its own. **Why the slug prefixes the section anchors.** Every note is on this page at once, so two notes both carrying `## Reading list` would mint the same id. `tabs.js` resolves an inbound `#...` by finding the panel that holds it, so a collision opens the wrong note — the tab name is the note's slug and the sections sit under `--...`, which keeps the two kinds of hash distinct as well as unique. Without JavaScript every panel renders, so this is one long page rather than a broken one — the same bargain `tabs.js` makes everywhere. {% endcomment %} {% if notes or coach %}
